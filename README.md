## 1. Connectigo｜无限流量，中秋活动价格划算

Connectigo 的特点是套餐选择简单：**月付、季付、年付标准套餐均为无限流量**，不用根据每月用量反复挑选流量档位。对于经常看视频、下载资料，或者每个月用量不固定的用户，这种方案比较省心。

标准套餐支持 **5 台设备**，页面标注不限速，提供使用文档和客服入口。另有 **¥1／2G 体验包**，方便在自己的网络下观察连接和晚高峰表现。
